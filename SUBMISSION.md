## One-paragraph summary (paste into the form)

TinigNa helps students give honest, safe feedback in the middle of the semester so instructors can improve a course while it is still running. Students join with a course code and send short ratings and an optional comment. No name or student ID is stored with feedback, duplicate responses are blocked with a hashed receipt kept apart from the feedback, and instructor summaries stay locked until at least five responses exist. Instructors see grouped themes and post actions that students read in "You Said, We Did". The project supports SDG 16 by making institutions more responsive, accountable, and transparent.

## Core features (for the form)

- Join a course with a code (no account for students)
- Anonymous feedback form with confirmation, loading, and success states
- Duplicate-response blocking without identity
- Instructor dashboard with a 5-response minimum, themes, and comments with identifying details removed
- You Said, We Did feed
- Close and reopen the feedback window

## Honest limits (say them if asked)

Data is stored on the device for the MVP. Instructor sign-in, a server backend, AI theming, and the Concern Reporting module are planned, not built.
