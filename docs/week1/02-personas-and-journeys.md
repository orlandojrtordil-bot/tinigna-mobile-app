# 2. Personas and user journeys

These personas are working hypotheses. Validate them with interviews (see file 01).

## Persona 1 (primary): The hesitant student

- 2nd or 3rd year student.
- **Goal:** tell the instructor what is not working in a course without being identified.
- **Fear:** that a critical comment could affect grades or relationships.
- **Needs:** a clear promise of anonymity, a short form, proof that something happened afterward.

### Journey: give anonymous feedback (Flow 2)

| Step | Screen | What the student does | Feeling and need |
|---|---|---|---|
| 1 | Student home | Opens the app, sees joined courses | Wants to get started fast |
| 2 | Join course | Enters the course code | Needs to know no name or ID is asked |
| 3 | Course home | Sees "Feedback open" | Knows there is a deadline |
| 4 | Feedback form | Rates pace, clarity, materials; adds an optional comment | Wants it short, about two minutes |
| 5 | Confirm submission | Confirms the anonymous submission | Needs reassurance it cannot be edited or traced |
| 6 | Submission success | Sees confirmation | Relief |
| 7 | You Said, We Did | Later sees what the instructor changed | Needs proof speaking up mattered |

## Persona 2 (secondary): The proactive instructor

- Wants to improve mid-semester but only gets a few scattered comments.
- **Goal:** clear, grouped feedback they can act on while the class is running.
- **Needs:** themes instead of a pile of comments, a way to tell students what will change.

### Journey: collect and respond (Flow 4)

| Step | Screen | What the instructor does |
|---|---|---|
| 1 | Sign in | Signs in |
| 2 | Instructor home | Sees courses and response progress |
| 3 | Create course | Enters course name and section |
| 4 | Share join code | Shares the code with the class |
| 5 | Dashboard | Watches the response count |
| 6 | Course responses | Reads anonymous comments |
| 7 | Themed summary | Sees themes (for example "Pace too fast, 9 mentions"). Locked until 5 responses |
| 8 | Post action response | Publishes what will change |

## Persona 3: Guidance office staff (concern reporting)

- Receives reports about bullying, rule violations, and safety hazards.
- **Needs:** an inbox with filters, a status for each report, a way to write a note back to the reporter.

### Journeys

Student (Flow 3): choose report type, describe what happened, submit anonymously, receive a tracking code (for example RPT-8K2M), check status (Received, Under review, Action taken, Closed).
Staff (Flow 5): sign in, open the reports inbox, open a report, update status and write a note.
